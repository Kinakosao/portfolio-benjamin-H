EcoDrop — API REST

API REST complète sur le thème de l'écologie. Gestion de points de collecte de déchets, types de déchets, dépôts et utilisateurs. Authentification par token JWT (Basic Auth), réponses JSON et XML, gestion des rôles USER/ADMIN, et leaderboard des 10 meilleurs recycleurs.

Points techniques :
  • Architecture REST complète (GET, POST, PUT, PATCH, DELETE)
  • Authentification JWT avec gestion des rôles
  • Réponses négociées JSON / XML
  • Déployé sur serveur Tomcat
Technologies utilisées :
Java REST API SQL Tomcat JWT

Syck Sai-Vhen — Shoot-em-up

Jeu de type shoot-em-up multijoueur développé en TypeScript avec une architecture client/serveur via WebSockets. Les joueurs se connectent depuis différentes machines et affrontent des vagues d'ennemis avec IA, un boss spécial, et un système de bonus.

Points techniques :
  • Architecture WebSocket temps réel (client TypeScript + serveur Node.js)
  • IA ennemis avec comportements paramétrés et boss final
  • Système de hitbox, collisions et projectiles
  • Contrôles hybrides clavier + souris
  • Top 10 des scores sauvegardé côté serveur
  • Tous les assets graphiques créés par l'équipe
Technologies utilisées :
TypeScript Node.js WebSocket

Déploiement Matrix/Synapse

Déploiement complet d'un serveur de messagerie instantanée Matrix (implémentation Synapse) sur une architecture distribuée de 3 machines virtuelles Debian 12, avec le client web Element.

Architecture :
  • VM matrix — Serveur Synapse
  • VM db — Base de données PostgreSQL
  • VM element — Client Element Web + nginx (reverse proxy)
Technologies utilisées :
Debian 12 Matrix/Synapse PostgreSQL nginx VirtualBox
