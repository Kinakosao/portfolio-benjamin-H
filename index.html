Application de Gestion de Stock

Ce projet est une application de bureau complète pour la gestion de stock. Elle permet de suivre les entrées et sorties de produits, de gérer les fournisseurs et de générer des rapports. L'interface a été conçue pour être simple et efficace, et l'application est connectée à une base de données MySQL.

Technologies utilisées :
Java JavaFX MySQL
